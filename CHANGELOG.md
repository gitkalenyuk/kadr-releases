# Changelog

What changed in the latest version of Kadr. More on the official website: https://kadr.uk/

## [1.1.9] - 2026-10-30

### Fixed

- Captions: Text tab edits apply to every selected caption in one step, with a new «Apply to all captions» switch; dragging or scaling in the player moves them all.
- The AI no longer builds tall columns of tracks: it reuses free tracks. Check project warns about too many tracks, and «Compact tracks» packs them.
- Shorts: hundreds of 9:16 templates are now exactly centred above the platforms' buttons (existing projects: Swap template on the graphic and pick the same template; your texts stay).
- Source check: when a site refuses downloads, the source says so and that an API key won't help.
